# Productivity with IntelliJ IDEA 

Sample code for the JetBrains "Productivity with IntelliJ IDEA" course.

This project contains samples and examples to help you learn to get the most from IntelliJ IDEA. You may recognise some of these examples from other projects. For example:

 - Code that demonstrates specific IntelliJ IDEA features likely came from https://github.com/JetBrains/intellij-samples
 - [Debugging](https://github.com/Getting2KnowIJ/debugging-code) and [running](https://github.com/Getting2KnowIJ/running-code) code tutorials come from the [Getting to Know IntelliJ IDEA](https://github.com/Getting2KnowIJ/) repos.

 For an example project that you can use to explore version control (VCS) features in IntelliJ IDEA, use https://github.com/Getting2KnowIJ/vcs-example
